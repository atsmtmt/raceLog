# raceLog

サーキット走行ログ（TrackAddict / RaceRender 形式の CSV）を可視化するブラウザツールです。

- **速度グラフ**（上段）: 選択したラップの速度を重ねて表示。横軸は「時間」「距離」を切り替え可能
- **G-G 図**（左下）: Accel X / Accel Y の散布図（0.5G 刻みの同心円つき）
- **コース図**（右下）: 緯度経度から走行ラインを描画

3 つの図はカーソル連動します。速度グラフ上でマウスを動かすと、同じ地点が G-G 図とコース図にマーカー表示されます。
速度グラフをズームすると、その区間だけが G-G 図とコース図で強調されます（コーナーごとの分析向け）。

## 使い方

ビルド・インストール不要です。

1. `index.html` をブラウザで開く
2. CSV ファイルをドラッグ＆ドロップ、または「ファイルを選択」で読み込む
3. 右下のラップ一覧で比較したいラップにチェック（最大 8 ラップ、既定はベストラップとその前後）

サンプルデータ `samples/` を「サンプルを読み込む」ボタンで開くには、ローカルサーバー経由で開いてください
（`file://` ではブラウザの制限でサンプルを取得できません。ファイル選択からは読み込めます）。

```bash
python3 -m http.server 8000
```

その後 http://localhost:8000/ を開きます。

### 操作

| 操作 | 内容 |
|---|---|
| ホイール | 速度グラフの横方向ズーム |
| ドラッグ | 表示範囲の移動 |
| ダブルクリック / 「ズームリセット」 | 全体表示に戻す |
| 時間 / 距離 | 横軸の切り替え（各ラップ開始を 0 とする） |
| OBD車速 / GPS速度 | 速度ソースの切り替え |
| X/Y 入替・横反転・縦反転 | G-G 図の軸調整（スマホの取付向きに合わせる） |

## データ処理

- 必須列: `Time`, `Lap`, `Latitude`, `Longitude`, `Speed (Km/h)`, `Accel X`, `Accel Y`（列順は問いません）
- ラップタイムはログ内の `# Lap N: hh:mm:ss.sss` 行（計測器の正式タイム）を使用。無い場合はラップ開始時刻の差
- 最初のラップはアウトラップ、最後のラップはインラップとしてベスト判定から除外
- GPS（約 1Hz）と OBD 車速（約 7Hz）は更新行（`GPS_Update` / `OBD_Update` = 1）の間を線形補間
- 距離は GPS 速度の積分で算出

## 構成

```
index.html      画面レイアウト
css/style.css   スタイル（ライト / ダークモード対応）
js/parser.js    CSV 解析・ラップ分割・補間・距離計算（Node からも require 可）
js/charts.js    Canvas 描画（SpeedChart / GGChart / TrackMap）
js/app.js       状態管理・ファイル読み込み・図の連動
samples/        サンプルログ（袖ヶ浦フォレストレースウェイ）
```
